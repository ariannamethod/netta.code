# Аудит Netta Lee / Netta Code

**Основной критерий приобретения опыта выполнен на художественном острове.**
На свежих seeds обученная Lee дала 40 продуктивных исполнений из 600, контроль —
19 из 600. Парное сравнение: 31 успех только у обученной версии против 10 только
у контроля, точное двустороннее p = 0,00145049. Условие p ≤ 0,05 задано в
[CONFIRMATORY_PROTOCOL.md](results/CONFIRMATORY_PROTOCOL.md).

Здесь продуктивный репертуар включает заново сгенерированные прежние успехи;
исходные программы корпуса и эквивалентные им результаты исключены. Генератор
выбирает продолжения из единиц и накопленных весов. Получение исходника прежнего
победителя из архива в генерации отсутствует. Открытия — отдельный показатель:
результаты, отсутствующие также во всей сохранённой истории успехов.

Во всех столбцах сначала указана обученная версия, затем контроль с той же
историей исключений. Каждый вариант получил ровно 600 сырых попыток.

На рисунках отключение нейронной головы при сохранении остальных приобретённых
механизмов даёт 23 продуктивных исполнения вместо 40 и 17 разных результатов
вместо 22. Парное p = 0,00455138. Это измеренный вклад головы в данном опыте.

Для строк положительное направление составляет 34 против 24, однако порог
0,05 не достигнут: p = 0,09873715. Для записей рост освоенного репертуара
сопровождается снижением открытий: **1 против 7 разных новых результатов**;
по попыткам открытия — 1 против 9, парное p = 0,0078125. Оба показателя оставлены
в отчёте. Вторичные острова оценены отдельно от основного критерия.

Проверка данных охватила все **5400 строк попыток** четырёх отчётов, включая
дополнительное отключение головы на рисунках. Заново пересчитаны распределения
статусов, числа различных программ и результатов, парные выигрыши/проигрыши и
точные p. Они совпадают с сохранёнными итогами. Проверены 16 совпадений SHA-256:
для каждого отчёта — организм, snapshot, evaluator и reader; текущие файлы
соответствуют зафиксированным версиям. Диапазоны seeds соответствуют протоколу.

Независимый CPython-verifier выполнил **355 засчитанных попыток**. Во всех четырёх
отчётах и соответствующих сырых записях: **0 ошибок независимого исполнения,
0 расхождений stdout, 0 допущенных копий корпуса**. Дополнительно сверены исходники
всех 355 попыток с корпусами после нормализации имён и их хеши результатов с
результатами корпусов. Общий [журнал тестов](results/tests_final.log) содержит
67 успешно завершённых тестов, включая продолжение состояния, неизменность
оценивания, переключение островов, отступы, ложные успехи и разделение метрик.

Первый опыт разработки и последующая диагностика сохранены. Репертуар был
выделен в самостоятельную метрику после диагностического анализа; приведённые
выше подтверждающие диапазоны 200000–203599 использованы по новому протоколу.
Открытия продолжают учитываться отдельно.

при `socket(): Operation not permitted`, затем SIGSEGV. В
